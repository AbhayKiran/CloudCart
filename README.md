# CloudCart

CloudCart is a production-style microservices-based e-commerce application designed to demonstrate an end-to-end AWS DevOps workflow.

## Application

- Product Service - Spring Boot
- Order Service - Spring Boot
- Frontend - HTML/CSS/JavaScript
- Database - PostgreSQL

## DevOps Stack

- GitHub
- Jenkins
- Maven
- Docker
- Amazon ECR
- Terraform
- Amazon EKS
- Kubernetes
- Helm
- AWS ALB
- Kubernetes HPA
- Amazon RDS PostgreSQL
- CloudWatch
- Prometheus
- Grafana

## Architecture

GitHub → Jenkins → Maven → Docker → ECR → Helm → EKS → ALB → CloudCart
